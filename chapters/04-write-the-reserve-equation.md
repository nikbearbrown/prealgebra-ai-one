# 4. Write the reserve equation

*Give the unknown a job before you try to move it.*

The household had $28.50 before shopping. The $3.00 basket leaves $25.50. It wants at least $18.00 to remain after an optional expense. Let s be the optional spending, in dollars. At the maximum allowed expense, the balance is exactly at the reserve:

`25.50 − s = 18.00`.

The equation names an equality, not a command to blindly move symbols. If you subtract the same amount from both sides of a true equality, it stays true. Adding s to both sides gives 25.50 = 18.00 + s. Subtracting 18.00 from both gives s = 7.50. Substitution checks the solution: 25.50−7.50 = 18.00.

## Change the words and see the math change

“At least $18 remains” describes more than the one equality case. Spending $4 leaves $21.50, which also works. Spending $8 leaves $17.50, which fails. For a nonnegative expense, all allowed values satisfy 0 ≤ s ≤ 7.50. Here we solved the boundary and reasoned from the fact that more spending reduces the balance. If the starting balance were already below $18, setting spending to zero would not meet the reserve. A negative answer from the equality would represent a required increase in funds, not permission for a negative purchase.

## Check in a second representation

Move to cents: 2550−s_c = 1800, where s_c is the number of cents. Subtraction gives 750 cents. Converting back gives $7.50. The cents version does not change the mathematics; it makes the dollar places harder to misread. Mixing 2550 cents and 18 dollars in one subtraction without conversion would give 2532 of what? The units are a test, not decoration.

Reverse the decision in one line: $18.00 reserve plus $7.50 maximum spend plus $3.00 basket equals the $28.50 pre-shop balance. That checks both the chosen basket and the spending limit.

**Try it unaided.** If the household buys the mixed basket instead, how much can it spend above the reserve? Write the equality, solve it and then show a value exactly one cent above the limit that fails.
